Componentes de um Computador

1.1 Componentes Internos

Os componentes internos são as partes que fazem um computador funcionar.

1.1.1 CPU

O processador é o cérebro do computador, responsável pelo processamento de dados.

1.1.2 Armazenamento

Dispositivos como HDDs e SSDs armazenam os dados permanentemente.

1.1.3 Memória

A memória RAM armazena temporariamente os dados em uso.

1.1.4 Fonte de Alimentação

Fornece energia elétrica para todos os componentes do computador.

1.2 Componentes Externos

Os componentes externos são dispositivos periféricos usados para entrada e saída de dados.

1.2.1 Teclado

Permite a entrada de caracteres e comandos.

1.2.2 Monitor de Vídeo

Exibe as informações processadas pelo computador.

1.2.3 Mouse

Dispositivo de apontamento usado para navegação.

1.3 Interfaces de Entrada e Saída

São conectores e protocolos que permitem a comunicação entre dispositivos.

1.3.1 Interfaces Sem Fio

Wi-Fi e Bluetooth são exemplos de conexões sem fio.

1.3.2 Áudio

Entradas e saídas de som, como P2 e P3.

2. Grandezas Elétricas

2.1 Potência Elétrica

Define a quantidade de energia consumida por um dispositivo.

2.2 Tensão Elétrica

Mede a diferença de potencial elétrico entre dois pontos.

2.3 Corrente Elétrica

Representa o fluxo de elétrons em um circuito.

3. Unidades de Medida Utilizadas na Informática

3.1 Capacidade de Armazenamento

Define o tamanho dos dados que podem ser armazenados.

3.1.1 bit

A menor unidade de informação digital.

3.1.2 Byte

Um conjunto de 8 bits.

3.2 Frequência

3.2.1 Hertz

Unidade de medida para ciclos por segundo.

3.3 Largura de Banda

Define a capacidade máxima de transmissão de dados.

3.4 Taxa de Transferência

Indica a quantidade de dados transmitidos em um tempo específico.
